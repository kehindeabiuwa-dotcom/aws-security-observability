# Project results

Use this folder to keep results from repeat runs of the [deployment guide](../docs/deployment.md). Record the date, region, stack, command, expected result and observed result.

Useful captures include stack completion, connectivity or event-routing checks, relevant logs, alarm history and cleanup completion. Keep secret values, credentials and tokens out of published captures. `private/` is ignored by Git.

For GuardDuty sample findings, keep the `[SAMPLE]` marker visible so the event type is clear.
